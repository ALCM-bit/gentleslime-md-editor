# GentleSlime — Md reader and editor

Editor de Markdown local-first e open source (MIT), com edição ao vivo no estilo Obsidian.
Desktop (Windows, macOS, Linux) e mobile (Android, iOS), feito com Tauri 2, Angular e CodeMirror 6.

- Spec do produto: `docs/spec.md`
- Regras para agentes de código: `AGENTS.md`
- Como preparar a máquina: `SETUP.md`
